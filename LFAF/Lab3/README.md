# Theory

Lexical analysis is the first stage of the compilation process. During this phase, the source code or input text is analyzed and divided into smaller units called lexemes. These lexemes are then categorized into tokens which represent the basic elements of the language.

A lexer (also called scanner or tokenizer) reads the input character by character and groups characters into meaningful sequences. Each sequence is recognized according to predefined rules of the language and assigned a token type.

For example, numbers, operators, parentheses or keywords can be identified as different tokens. The lexer does not analyze the full meaning of the program, but only separates the input into components that will later be processed by other stages such as syntax analysis.

In this laboratory work a simple lexer was implemented in Python that can analyze mathematical expressions containing integers, floating point numbers, operators and trigonometric functions.

# Implementation description

The project was implemented in Python and contains two main classes: `Token` and `Lexer`.

The `Token` class represents a token generated by the lexer. Each token has a type and a value. The type represents the category of the lexeme (for example INTEGER, FLOAT, PLUS, SIN), while the value represents the actual text extracted from the input.

The `Lexer` class performs the lexical analysis. It receives an input string and scans it character by character. Depending on the characters encountered, it groups them into tokens.

Several helper functions were implemented in this class. A function for skipping whitespace characters allows the lexer to ignore spaces in the input. Another function reads numbers and determines whether they represent integers or floating point numbers. A separate function processes alphabetical sequences and identifies function names such as `sin` and `cos`.

The main scanning function analyzes the input and generates tokens corresponding to operators, parentheses, numbers or identifiers. The process continues until the entire input string has been analyzed.

    lexer = Lexer(text)
